# Fast diagnostics against the dense path

CPU only, 2 threads; causal softmax attention with sink and locality bias, symmetrised, sym-normalised Laplacian. Timing: best of 3 runs for S <= 512, single run above; seconds. Measured on a laptop under concurrent load: repeat runs differed by up to about 30% at S >= 1024. Generated by `fast_vs_dense.py`.
